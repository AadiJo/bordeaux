The main branch now resolves every open Bordeaux Lab issue and makes linked path endpoints behave as one shared waypoint without changing canonical project geometry or release boundaries.

Context

The work covers Lab issues 41, 45, 50, 52, and 55. It also hardens the endpoint-link feature already present on main: Append creates a link from the prior path end to the new path start, manual links remain available in the path library, and edits propagate in either direction.

The optimizer branch was not modified. Its pre-existing working changes were preserved in a named Git stash before switching to main.

Review outcome

Approved after one blocking fix. Independent review reproduced an already-aborted request that could still start an agent planning job. The service now rejects that signal before invoking the worker, with a focused regression proving the runner is never called.

No unresolved blocking findings remain. The implementation keeps project and planner data canonical in SI, limits UI preferences to machine-local storage, and leaves generated release artifacts and product-owned checkpoint refs untouched.

Implemented surface

  • Playback clocks use external stores and small consumers, so animation frames no longer commit the root editor tree.
  • Agent analysis, repair, and route generation run in a cancellable worker; Java trajectory generation retains its existing worker boundary.
  • A shared pointer controller handles capture, pointer identity, cancel, lost capture, blur, cursor restoration, and unmount cleanup across all legacy drag sites.
  • Direct manipulation stays available in Waypoint mode; 1–5 provide clustered tool aliases while V/W/R/M/C remain supported.
  • Export failures have a persistent red alert and affordance; field orientation is presented as a pure 180-degree flip and no longer supplies physical alliance ownership defaults.
  • Wheel deltas are normalized and bounded. Metric/imperial display conversion is global and persistent while project state, validation, planning, and Java export remain SI.
  • Packaging documentation defines recoverable artifact archiving and protects T3/Codex checkpoint refs. Package verification now requires the planning worker.
