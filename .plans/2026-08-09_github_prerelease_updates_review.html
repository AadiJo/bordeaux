Bordeaux now has a fail-closed GitHub beta release pipeline and a packaged-app updater that protects unsaved projects.

Outcome

The public Zw96042/bordeaux repository is the anonymous update feed. Version 0.2.0-beta.1 configures electron-updater for the beta channel, adds automatic and manual checks, downloads updates in the background, and offers restart only after a second clean-project check.

Release contract

The manual workflow accepts only main, requires a new checked-in beta version, runs the full app verification, requires both platforms' signing credentials, validates the packaged feed and public manifests, creates the version tag atomically at the dispatched commit, and publishes only after both platform builds succeed.

No unsigned fallback exists. The first live release intentionally remains unavailable until the repository has the required Apple and Windows signing secrets.

Independent review

The first read-only release review found four blockers: implicit downgrade permission, non-main dispatches, pre-existing tag ambiguity, and unverified public beta manifests. All four were fixed. A follow-up review confirmed the fixes and found no new blocker.
