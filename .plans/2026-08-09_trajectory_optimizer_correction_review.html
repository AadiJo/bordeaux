Final implementation and verification record for Bordeaux’s corrected fixed-path optimizer and explicit Bezier geometry-refinement preview.

Context

The original Optimized planner inherited Profiled velocity samples as hard ceilings, so it could not improve traversal time and could still report false infeasibility under affine drivetrain constraints. The correction follows the approved correction plan while preserving authored geometry, stops, actions, migrations, static-renderer parity, and bounded resource behavior.

Recommendation

Ship the complete controllable-interval fixed-path retimer, independent physical constraints and resampled validation, then expose geometry changes only through the explicit Refine path preview. Continue describing the timing result as time-optimal only for Bordeaux’s discretized fixed-path model; describe handle search as geometry refinement, not Sleipnir-equivalent global optimization.

Implementation steps

  1. Removed the inherited Profiled speed ceiling and added explicit stops, exact policy boundaries, curvature, angular, drivetrain, and per-module longitudinal motor torque-speed constraints.
  2. Replaced scalar-only backward reachability with full controllable squared-speed intervals and added an independent short-case oracle.
  3. Added fresh two-times geometry resampling for every accepted Optimized trajectory and eight-times dense Profiled comparison in release gates.
  4. Mirrored the solver, validation, resource preflight, and diagnostics in the static renderer.
  5. Added cancellable Bezier handle-length refinement with path-check rejection, stale-state containment, overlay, Apply/Dismiss, and one-step undo.

Review disposition

An independent Codex review identified endpoint and per-module motor safety, longitudinal-versus-total module acceleration, fake dense validation, geometry-candidate path errors, sample-ceiling divergence, narrow-set tolerance, stale Apply state, and missing real motor fixtures. Each finding has a focused code change and regression test. Remaining product work is the later TrajoptLib comparison and broader nonlinear geometry freedom; neither is claimed by this release.
